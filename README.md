# truecornerland.com

The website for True Corner Land Co. (a branch of Shortfin Labs LLC), served by GitHub Pages.

The page was designed by Atrium's Architect (the editorial direction) and finished by hand: photos, buttons,
the mailing address, and a static-host security policy. It's one self-contained `index.html`.
